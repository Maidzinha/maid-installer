# Ícones dos apps do catálogo

Os 61 ícones em `src/MaidInstaller.App/Assets/AppIcons/<id>.png` (64×64, PNG com transparência) foram baixados **dos sites oficiais** de cada programa (favicon / ícone de app do próprio site), sem edição além de redimensionar.

- Eles aparecem só quando o Windows não tem o ícone real do programa (por exemplo, antes de instalar). Depois de instalado, o app usa o ícone do Menu Iniciar.
- Os ícones e marcas pertencem aos seus donos; estão aqui só para identificar o programa na lista.
- Para trocar um ícone: substitua o PNG com o mesmo `id` do `catalog.json`. Se o arquivo não existir, a tela mostra a letra inicial do app.
